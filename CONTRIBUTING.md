# Cómo contribuir

- **Señalar un proyecto**: usa el botón «Proponer para revisión» de cada ficha o la plantilla de issue. Aporta hechos y fuentes; no datos personales de particulares.
- **Código**: la web es HTML/JS sin compilación (`site/`) y el ETL es Python estándar (`etl/`). Abre un PR pequeño y descriptivo.
- **Nuevos indicadores**: deben ser reglas objetivas, documentadas en `docs/METODOLOGIA.md` y con texto en `site/i18n.js` (ES y EN).
- **Traducciones**: añade un idioma en `site/i18n.js`.
